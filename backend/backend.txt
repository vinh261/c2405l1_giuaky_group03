Responsive sidebar

Logout functionality

2. DashboardStats.tsx - Tổng quan thống kê
Cards hiển thị stats
Charts cho categories
Most favorited meals
Recent activities

3. UserManagement.tsx - Quản lý users
Search & filter
Toggle admin/user role
Delete users
User statistics

4. MealManagement.tsx - Quản lý meals
CRUD operations
Search & filter by category
Pagination
Sử dụng MealFormModal có sẵn

5. CategoryManagement.tsx - Quản lý categories
Add/Edit/Delete categories
Hiển thị số meals trong category
Prevent delete nếu còn meals

6. TagManagement.tsx - Quản lý tags (simplified)
Grid view
Add new tags
Show meal count

Bạn đã tạo thêm ReviewManagement.tsx, FavoriteStats.tsx và AdminController.php, bạn đang tạo routes admin cho tôi thì đoạn chat bị giới hạn, dưới đây là admin routes bạn đang tạo, thì trong api routes của tôi đang có ProfileController như file txt lúc nãy tôi vừa gửi, nên tôi không biết là có nên xóa hay giữ nguyên.
// Admin routes (add after existing routes)
Route::middleware(['auth:sanctum', 'admin'])->prefix('admin')->group(function () {
    // Dashboard
    Route::get('/dashboard-stats', [AdminController::class, 'dashboardStats']);

    // Users management
    Route::get('/users', [AdminController::class, 'users']);
    Route::patch('/users/{user}/role', [AdminController::class, 'updateUserRole']);
    Route::delete('/users/{user}', [AdminController::class, 'deleteUser']);

    // Categories management
    Route::get('/categories', [AdminController::class, 'categories']);
    Route::post('/categories', [AdminController::class, 'createCategory']);
    Route::put('/categories/{category}', [AdminController::class, 'updateCategory']);
    Route::delete('/categories/{category}', [AdminController::class, 'deleteCategory']);

    // Reviews management
    Route::delete('/reviews/{review}', [AdminController::class, 'deleteReview']);

    // Favorites statistics
    Route::get('/favorites/stats', [AdminController::class, 'favoritesStats']);
});

Còn dưới đây là những gì chúng ta đã làm cùng nhau trong frontend: mình dùng react 19+, typescript 5.8, zustand, zod, react-hook-form, tanstack-query 5.8, tailwindcss v4, ... còn backend mình dùng laravel sanctum cookie-based, nếu cần thêm thông tin gì thì bạn cứ hỏi nha, mình sẽ cung cấp.
